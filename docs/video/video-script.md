### 需要注意的事实

1. 渠道不止微信、飞书：README 还有 Telegram、Slack、Discord（填 token 接入）。口播只讲微信和飞书，其余放在 B 站版花字里。
2. 「手机」仍然是通过微信或飞书，**没有独立手机 App**，口播里主动说明。消息会经过对应平台，口播也要说。
3. 电脑操作：默认「自动执行」，可切成「改变界面前先问我」；**macOS 上是 Beta**。录制用 Linux，花字标出 macOS Beta。
4. 权限有三档，界面文案是：只读 / 工作区可写（默认）/ 完全权限。沙箱只限制写文件，所以读工作区外的文件不弹审批。审批按钮叫「允许（仅本次）」。
5. 新增能力：后台任务与规则、应用内群聊（0.1.16）、界面有英文版。旧设计稿里「仅中文」「无多机器人协作」已不再准确，本脚本以线上为准。
6. 模型数量：价格接口现在是 71 个，README 写的是「70+」。口播不念数字。
7. README 顶部有同类产品对比和 Modelflare 的限时活动，官网价格区有订阅制对照表和限时线路，**都不入镜**。拍 README 一律用锚点直跳。
8. API 域名控件提供三个域名和手动测速，不按地域推荐。花字写「可先测速，域名自己选」。历史配置的「自动」仍指向主域名。
9. 仓库在 `modelflare-ai` 组织下，模型费用付给 Modelflare，所以片内和文案都写明这两点。
10. 仓库没有 `README.zh-CN.md`，中文版就是 `README.md`，英文版是 `README_en.md`。
11. Linux 下的电脑操作实测：启动应用、输入英文能完成；中文可能只打出前两个字，GTK 的「另存为」对话框操作不了。
12. 仓库 About 和页面标题写着竞品名，所有 GitHub 镜头都不能露出。

## 2. 口吻与措辞规则

每个能力后面都接一句边界，不夸大，也不声明旁白和项目的关系。

**要做**：中性介绍，用「它」「你」；先说是什么、能装在哪；每个能力后面接一句边界（越界会先问、屏幕内容会发给模型、消息会经过对应平台）；数据去向用原文说法「会离开你的设备」；写明项目在 Modelflare 的 GitHub 组织下、模型费用付给 Modelflare；结尾说明版本还早期；引导去 GitHub 看项目。

**不要做**：

- 不用「我做了」「我是作者」「我们的项目」「我们自己的服务」。
- 不写「不是推广」「不是广告」「没有商单」「和项目无关」「自费」「第三方评测」。
- 不用「最」「第一」「全网」「颠覆」「秒杀」「碾压」；不用「绝对」「100%」「零风险」「完全安全」。
- 不出现「限时」「优惠」「福利」「免费领」「点击」「下载链接」「关注」「私信」。
- 口播和文案不比较别的产品，不点名竞品。B 站版的画面按真实页面拍，页面上本来就有的内容不用避开。
- 不写「零遥测」，只能说「项目自己的代码里没有遥测，第三方组件它不作保证」。
- 不念价格数字，不拍价格页、计算器、用量弹窗、余额和充值入口。
- 片内不写 AI 合成，由发布者在平台勾选声明。
- 不给六个角色绑岗位或擅长的事：角色只有名字和长相不同，机器人做什么由人设决定。
- 不出现 Folkbench。

## 3. 主版本（9:16，约 89 秒）

主版本用于抖音和小红书，所以网页镜头都没有地址栏，花字和结束卡不出现网址。

规格：1080×1920，30 fps，H.264，AAC，响度 -16 LUFS，真峰值 ≤ -1 dBFS。录屏 1080×1240 贴在画布 y=100–1340；字幕中心在 y≈1440（约 75%）；花字不进上方 220 像素和下方 380 像素。全片无背景音乐。

**时间码说明**：时间码是按口播字数（约 4 字/秒）加句间停顿算出的预估，实际以 TTS 导出的每镜头音频长度为准，镜头长度跟音频走。转场目前全部是硬切，不用溶解。

## 7. TTS 语音合成指南

首选 MiniMax `speech-2.6-hd`，全片固定一个音色和语速。服务商的参数名、音色名和限额会更新，生成前以控制台当天的文档为准；这部分沿用 v1.0，v1.1 没有重新核对。

### 7.1 选型（已决定）

| 角色 | 模型 / 服务 | 说明 |
| :-- | :-- | :-- |
| **首选** | **MiniMax `speech-2.6-hd`**（同步 T2A v2 接口） | 中文自然度好；`voice_setting` 可调语速、音量、音调、情绪；`pronunciation_dict` 可以固定 AnyModelBot、Modelflare 这类词的读法；支持逐段合成。 |
| 备选 1 | 火山引擎「豆包语音合成模型 2.0」（`seed-tts-2.0`） | 通用场景音色多、有语气表现；`speech_rate` 保持 0。适合首选听感不满意时整条替换。 |
| 备选 2（开源，可离线） | **CosyVoice 3**（Apache-2.0） | 想在自己电脑上跑时用；`instruct` 模式写「用平稳、自然、略低沉的男声朗读」，速度参数 1.0。 |
| 不推荐 | Fish Speech / OpenAudio S1 | 开源权重是非商业许可（CC-BY-NC-SA），S1 即将下线（官方通知 2026-12-31），不适合长期使用。 |

### 7.2 音色与参数（MiniMax，起点值）

- 音色：中文**男声、青年、不要播音腔、不要营销感**。先在控制台的音色库试听 `male-qn-qingse`（青涩青年音色）以及其他「青年 / 沉稳」男声，选一个**听起来像在平常说话**的；选定后整套视频固定同一个音色，不换。
- 请求体（示意）：

```json
{
  "model": "speech-2.6-hd",
  "text": "（每个镜头一条，用 3.3 / 4.3 的 TTS 输入稿）",
  "stream": false,
  "voice_setting": {
    "voice_id": "male-qn-qingse",
    "speed": 1.0,
    "vol": 1.0,
    "pitch": 0,
    "emotion": "calm"
  },
  "pronunciation_dict": {
    "tone": ["AnyModelBot/Any Model Bot", "Modelflare/Model flare", "MIT/M I T", "GitHub/Git Hub"]
  },
  "audio_setting": { "format": "wav", "channel": 1 }
}
```

- **语速**：目标约 4 字/秒。先合成 S02 试听，实测小于 3.8 字/秒就把 `speed` 调到 1.05，大于 4.4 字/秒调到 0.95；**全片统一一个值**，只在整体不合适时调，不逐句调。
- **情绪**：`calm`。不要用 `happy` 或 `excited`，不然会有营销感。
- 采样率：用服务支持的最高值导出，剪辑软件里统一转 48 kHz、单声道。
- 一个镜头一条音频，命名 `S01.wav`…`S10.wav`、`B01.wav`…`B12.wav`；镜头之间在剪辑软件里留 0.3–0.5 秒的呼吸；S04 的「会离开你的电脑」后面留 0.8 秒。

实际喂给 TTS 的文本，每一个英文词的写法已经在 3.3 / 4.3 里替换好。字幕和花字使用原文，**不要把读音写法放到画面上**。

### 7.4 验收

合成后逐条听一遍：品牌词读音一致；没有吞字；「会离开你的电脑」那句语速不被压缩；没有机械的停顿。不满意就重新合成该镜头，不手工拼接半句。

## 8. 字幕、花字与后期规范

后期只做指向和标注，不制造录屏里没有的东西。

- **字幕**：烧录硬字幕，放在录屏下方（约 75% 高度），思源黑体 Medium（或苹方），1080 宽画布上字号 58 像素，白色 `#fafaf7`，描边 4 像素 `#060706`，每行不超过 14 个字、最多两行；关键词（如「这部分会离开你的电脑」「MIT 开源」）用 `#d7ff00` 底色块、字用 `#161a00`。
- **对轴**：先把整段音频放进剪映或 Premiere 自动识别字幕，再把识别文本**逐条替换成 3.2 / 4.2 的原文**（保证品牌词、MIT、GitHub、Modelflare 是原样），不要保留识别错字。
- **花字**：同一画面最多一条主花字加一条小字；小字号不低于 36 像素；花字不出现网址。
- **加速**：只对打字、等待模型和多张审批卡片的段落加速，必须有「已加速 ×N」标注。
- **推进（zoom）**：只用于指向要看的位置，0.4 秒 ease-out，不抖动、不旋转。
- **裁切**：主版本的浏览器镜头都裁掉地址栏。
- **音频**：只有旁白，无背景音乐；响度 -16 LUFS，真峰值 ≤ -1 dBFS。
- **画面检查**：逐帧确认没有 Key、令牌、余额、充值入口、邮箱、二维码、真实用户名。
